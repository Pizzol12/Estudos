# NextBank — Projeto final

Entrega final de um projeto acadêmico de modelagem de dados aplicado a um cenário bancário fictício.

## Conteúdo

- Apresentação final do projeto;
- Relatório em PDF;
- Painel e visualizações no Power BI.

## Objetivos de aprendizagem

- Modelar informações de um domínio bancário;
- Criar indicadores e visualizações;
- Apresentar uma solução técnica de forma estruturada.

> Os arquivos deste repositório representam a documentação e a apresentação acadêmica do projeto.
