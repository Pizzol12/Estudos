# Estudos iniciais de HTML

Exercícios realizados durante as aulas de desenvolvimento web da graduação em Ciência da Computação.

## Conteúdo

- Estrutura básica de uma página HTML;
- Elementos semânticos;
- Imagens e links;
- Campos de formulário.

Projeto acadêmico desenvolvido durante as aulas, com participação do professor e de colegas registrada no histórico de commits.
