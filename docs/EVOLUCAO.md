# Registro de evolução

Os projetos deste repositório nasceram como exercícios acadêmicos e práticas pessoais. Na organização inicial foram preservados os objetivos originais, com correções de sintaxe, validação de entradas e documentação para facilitar a execução.

## Competências praticadas

- Variáveis, operadores e estruturas condicionais;
- Laços de repetição, arrays e métodos;
- Algoritmos de ordenação e análise de complexidade;
- Interfaces gráficas simples com Tkinter;
- Matrizes e visualização de dados;
- Recursão e persistência local em JSON;
- Uso básico de Git e GitHub.

## Próximos passos

- Escrever testes automatizados para todos os projetos;
- Criar aplicações orientadas a objetos em C#;
- Integrar um projeto com banco de dados SQL;
- Publicar projetos web autorais.
