# Classificador de faixa etária

Programa de console que recebe uma idade, valida a entrada e informa a faixa etária correspondente.

## Conceitos praticados

- Entrada e saída de dados;
- `int.TryParse` para validação;
- Expressão `switch`;
- Interpolação de strings.

## Executar

```bash
dotnet run
```
