# Fundamentos interativos em C#

Menu de console que reúne exercícios de tabuada, soma de números e preenchimento de arrays com valores aleatórios.

## Conceitos praticados

- Métodos e parâmetros `out`;
- Estruturas `while`, `for` e `switch`;
- Arrays;
- Geração de números aleatórios;
- Validação de entrada.

## Executar

```bash
dotnet run
```
