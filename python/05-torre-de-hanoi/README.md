# Torre de Hanói

Jogo de terminal baseado no quebra-cabeça clássico da Torre de Hanói.

## Funcionalidades

- Partidas com 3 a 8 discos;
- Validação das regras do jogo;
- Exibição visual das torres no terminal;
- Sistema local de recordes em JSON;
- Ajuda e sugestões de movimento;
- Solução recursiva do problema.

## Executar

```bash
python main.py
```

O arquivo `hanoi_scores.json` é criado automaticamente ao registrar um recorde e não é enviado ao GitHub.
