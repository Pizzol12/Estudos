# Calculadora de IMC

Aplicação com interface gráfica para calcular e classificar o Índice de Massa Corporal.

## Conceitos praticados

- Funções com responsabilidade única;
- Validação e tratamento de exceções;
- Interface gráfica com Tkinter;
- Formatação de números.

```bash
python main.py
```

> O IMC é uma referência geral e não substitui avaliação profissional.
