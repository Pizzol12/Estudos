# Calculadora da Lei de Ohm

Programa criado para um trabalho de Física. Calcula resistência, corrente ou tensão a partir da relação `V = R × I`.

## Conceitos praticados

- Funções;
- Validação e tratamento de erros;
- Operações matemáticas;
- Aplicação interdisciplinar de programação e física.

python main.py
